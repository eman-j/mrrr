# مكة المكرمة — رحلة إلى بيت الله الحرام

موقع تعريفي ثابت (ملف HTML واحد، بدون أي أدوات بناء) عن مكة والكعبة والمسجد الحرام ومناسك الحج والعمرة.

## النشر على GitHub Pages
1. ارفع الملفات إلى مستودع جديد (الفرع `main`).
2. من Settings ثم Pages اختر Source: Deploy from a branch، والفرع `main`، والمجلد `/ (root)`.
3. بعد دقيقة أو اثنتين يظهر الموقع على `https://USERNAME.github.io/REPO/`.
